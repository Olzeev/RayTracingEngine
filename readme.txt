Сборка проекта - как в шаблоне
cmake -B build && cmake --build build

Аргументы командной строки:
-h, --help
-bunny - создать кролика
-gun - создать пушку
-cube - создать куб
-cyl - создать 'MotorcycleCylinderHead'
-shadow - включить жесткие тени
-camera - настроить камеру (позиция, направление, скорость, чувствительность)

Папка models должна быть там же, где и main.cpp
